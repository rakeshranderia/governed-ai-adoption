# Anonymised Case Study — Governed Generative AI Pilot

An organisation of approximately 120 people wanted to explore generative AI while maintaining appropriate privacy, security and information-handling controls.

Approximately 40 users were given access to the approved platform. Use cases included tender/proposal assistance, data analysis, coding assistance/QA, drafting and summarisation.

Governance included acceptable-use guidance, privacy considerations, DLP/data handling, approved-platform rules, Shadow AI controls, user training, human review and education on bias/hallucinations.

Usage reporting was extracted through Microsoft Graph using `Reports.Read.All` and Microsoft 365 usage-report endpoints, then combined with user feedback, use-case examples, productivity estimates, support requests and incidents/exceptions.

The pilot provided evidence for decisions on value, training, control refinement, scaling and restriction.

**Governance → Pilot → Adoption → Measurement → Scale**
