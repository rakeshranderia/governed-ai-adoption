# Implementation Roadmap

## Phase 1 — Prepare
Sponsor, platform, pilot objective, privacy/security baseline, acceptable-use guidance, data handling and incident path.

## Phase 2 — Pilot
Select cohort, train users, publish example use cases, capture feedback and monitor Shadow AI demand.

## Phase 3 — Measure
Gather usage telemetry, survey users, capture high-value use cases, assess quality/productivity, review incidents and analyse licence utilisation.

## Phase 4 — Refine
Improve guardrails, retire weak use cases, strengthen controls for higher-impact uses and close training gaps.

## Phase 5 — Scale
Expand selectively, embed proven patterns, continue measurement and introduce formal risk tiering for higher-impact AI.
