# AI Adoption Operating Model

## Governance
Approved platforms, acceptable use, data classification, DLP, privacy, security, human oversight, supplier review, incident reporting and exception handling.

## Pilot
Use a bounded cross-functional cohort large enough to generate real usage patterns but small enough to support closely.

## Adoption
Provide training, examples, safe-use reminders, support channels and peer learning.

## Measurement
Measure active users, repeat use, use cases, time saved, quality, user confidence, incidents, exceptions and cost.

## Scale
Scale only when value is visible, risks are understood, controls are working and the support model is sustainable.
